# 学习模型 / Learning model

## 每日旅程

- **复习**：所有到期的词（FSRS 计算的 `due` 已过）。
- **新词**：每天上限可设（默认 10），从学习路线中你的起点难度开始取未学过的词。
- 顺序：先复习，再以 5 个为一组学新词：先「初见」认识 5 个词，再打乱顺序回忆这 5 个词。

## 如何增加首页进度

首页 A1～C2 按钮只筛选图鉴；打开词条、看图、播放发音和收藏不会增加「已学」。需要从 A1 安排新词时，先在「我的 → 从哪个难度开始」选择 A1，再点击首页「开始今天的旅程」，看完初见卡片并点击「认识了」，再完成回忆题。初见卡片只推进任务步骤；真正的首次作答才建立记忆记录。

- 「已学 / 已点亮」：有记忆记录的不同单词数量。新词首次作答后增加，答错也会记录为学习中。
- 「今日答题」：每个词在本轮中的首次作答数量；答错后的重试不重复累加。已有单词的新一轮复习会增加答题数，已学单词总数不会重复增加。
- 「已掌握」：达到 FSRS 复习状态、记忆稳定度至少 21 天的单词数量，需要持续复习。
- 打字练习：单独保存 WPM、准确率和练习记录，不改变上述记忆指标。

作答后无需完成整轮才保存；可以暂停返回首页，稍后继续。登录后先保存在账号隔离的本机缓存，再自动同步。导入与跨设备接续保留评分和待继续状态，避免重复计分。云端同步未完成时，以账号栏显示的状态为准。

## 题型

| 题型 | 适用 | 说明 |
| --- | --- | --- |
| 选义 | 新词、记忆弱 | 看英文选中文，干扰项词性相同 |
| 看图补句 | 新词、记忆弱 | 插画 + 挖空例句，选英文词，干扰项拼写相近 |
| 听音辨词 | 各阶段 | 只听发音选词 |
| 拼写 | 稳定度较高 | 看图和释义拼写，可以逐字母提示（提示后最多计 Hard） |

## 评分与 FSRS

每个词在一轮中只有**第一次作答**更新记忆（ts-fsrs，FSRS-6，默认目标记忆率 90%）：

- 答错 → Again
- 答对但慢、或用了提示 → Hard
- 答对 → Good；拼写又快又对 → Easy

答错的词会在几题之后换一种题型再练一次（最多两次），重试不再评分，也不计入正确率。

「已掌握」= FSRS 复习状态且记忆稳定度 ≥ 21 天。

## 打字练习

打字只训练输出，不改变记忆状态。WPM 按每 5 个正确字符计 1 词。
